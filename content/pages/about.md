## 关于本站

你好，我是 **知途** 👋。这里是我的**个人博客 + 知识库**——用来记录、整理、沉淀技术与生活点滴。这个站点是自用的**个人知识库**，用于整理技术笔记、读书心得与生活随笔。

站点的特别之处在于：文章渲染效果与 **Typora 导出 HTML** 保持一致的风格与配色，而这套配色来自开源的 [Phycat](https://github.com/sumruler/typora-theme-phycat) 主题。

> [!NOTE]
> 你可以通过右上角的「主题」按钮随时在 **11 套配色** 之间切换（8 套亮色 + 3 套暗色），选择会被浏览器记住；也可以点「主题」→「自定义」打开配色工坊，自制专属主题配色并导出为新主题。

## 本站特性

- 🎨 与 Typora 导出一致的渲染：标题图标、渐变 H2、毛玻璃卡片、Mac 风格代码块、任务列表动画、提示块、Mermaid 图表
- 🔍 **站内全文搜索**：标题 / 正文 / 分类 / 标签都能搜，按 <kbd>Ctrl</kbd> + <kbd>K</kbd> 随时唤起
- 🎨 **自定义主题**：「主题」→「自定义」打开配色工坊，自制主题色一键应用到全站，可导出为新主题文件
- 🗂️ 知识组织：首页分类卡片 + 标签云 + 按年月的归档页
- 📊 阅读体验：顶部阅读进度条、字数与预计阅读时长、正文图片灯箱（滚轮缩放 / 拖拽平移）、多级目录、代码一键复制
- 📦 **PWA**：可"安装"到桌面 / 手机主屏，Service Worker 缓存支持离线阅读
- 📱 响应式布局 + 纯静态站点，多端查看、可部署到任意静态托管

## 写作约定

文章的 **YAML front matter** 用于标记元信息：

```yaml
---
title: 文章标题
date: 2026-08-01
updated: 2026-08-01
category: 技术笔记
tags: [标签1, 标签2]
excerpt: 一句话摘要（用于首页卡片）
---
```

- `date` 用于排序；`updated` 表示最近更新时间（改了文章记得同步更新，文章页会显示"更新于"）
- 可选开关（文章与独立页面通用，默认全开）：
  - `toc: false` —— 不显示目录侧栏；
  - `tocnum: false` —— 保留目录侧栏，但侧栏目录项不显示编号；
  - `headnum: false` —— 正文标题不显示编号。
  > 本页就使用了 `toc: false` + `headnum: false`（无目录、标题不带编号）。
- 图片放在 `content/posts/images/<文档名>/` 下，正文用相对路径引用，例如 `![](images/<文档名>/xxx.png)`
- 保存文件后运行 `npm run build`（或 `npm run serve` 预览）即可看到更新
